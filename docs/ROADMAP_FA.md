# نقشهٔ راه دارا

## اکنون

`pydara.tse`: دادهٔ بورس، ابزارها، قیمت و تاریخچه، دریافت گروهی، کلاینت همگام و
ناهمگام، کش و SQLite و خروجی فایل.

## مراحل بعدی (پیاده‌سازی نشده)

- ماژول‌های داده برای بیتکوین و سایر رمزارزها، دلار و ارز، طلا و بازارهای کشورهای دیگر.
- ماژول مستقل تحلیل با قرارداد ورودی و خروجی مشخص.
- ماژول مستقل ML با وابستگی‌های اختیاری و بدون تحمیل آنها به دریافت داده.

ماژول‌های آینده کنار `tse` زیر بستهٔ `pydara` قرار می‌گیرند.
این سند، نام یا منبع دادهٔ قطعی برای قابلیت‌های آینده تعیین نمی‌کند.
